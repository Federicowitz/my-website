Datafalco

Full Stack - web app di Business Intelligence

Piattaforma SaaS in produzione: integrazione bidirezionale con le API di Fatture in Cloud, parser XML fatturazione elettronica Ospitata su Supabase e Render.

Un programma che controlla prezzi e volumi dalle fatture al posto tuo: le legge, le controlla e ti dice dove guadagni e perdi.

UltraShare

Trasferimento file peer-to-peer, senza server intermedio.

Infrastruttura di trasferimento P2P crittografata senza relay cloud: scrittura diretta su disco via stream, con controllo del backpressure per non saturare la RAM su file di grandi dimensioni. Basata su WebRTC DataChannels.

Manda file enormi da un computer all'altro, senza passare da internet o da un server di mezzo.

Remandio

Base di conoscenza personale, locale e a schema libero.

Personal knowledge base ad architettura locale: definizione dinamica degli schemi a runtime, importazione da liste testuali non strutturate, sincronizzazione deterministica via merge JSON.

Un'agenda personale che si adatta a come vuoi organizzare le tue cose, non il contrario.

WriteX / Scrybix

Pagina locale per il versioning della scrittura, con opzione cloud.

Ambiente di scrittura e versioning non lineare a grafo, con creazione di grafi ed entità personalizzate, storage locale via IndexedDB e sincronizzazione cloud opzionale. Espone un bridge runtime per la co-scrittura programmatica con agenti IA.

Un posto per scrivere storie dove puoi creare personaggi e collegamenti come una mappa, e tornare indietro nel tempo a qualsiasi versione.

File Stager

Estensione VS Code, ponte tra l'albero file e la clipboard di sistema.

Estensione che elimina l'attrito tra il file tree di VS Code e il file manager del sistema operativo: copia e incolla bidirezionale di file e cartelle tramite le API native dell'OS.

Un trucco per programmatori: rende più veloce copiare e spostare file dentro e fuori dall'editor di codice.

Timetable solver

Motore a vincoli per generare orari scolastici.

Risolutore a programmazione vincolata (Google OR-Tools, CP-SAT): minimizza i buchi in orario, gestisce compresenze di laboratorio, vincoli a blocchi consecutivi e il congelamento di assegnazioni parziali.

Fa gli orari scolastici al posto delle segreterie, senza buchi e senza litigate tra docenti.
