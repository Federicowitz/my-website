C++ · LABORATORIO 13 · 7 PASSI GUIDATI

Struct e dati dei personaggi

Dalle variabili separate a un tipo che raggruppa i dati. Prima i dati, poi le operazioni: è il ponte verso classi e oggetti.

Parti dalla spiegazione del capitolo 13. Ogni esempio qui aggiunge un concetto: puoi distribuire il laboratorio su più incontri. Gli ultimi passi riprendono il ciclo di gioco, con regole visibili e risultati riproducibili.

Ogni esempio è indipendente. Crea un file main.cpp e copia un programma completo alla volta: non incollare più main nello stesso file. Compila con g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o gioco. Avvia .\gioco.exe in PowerShell oppure ./gioco su macOS/Linux. Salva e ricompila dopo ogni modifica.

Negli esempi brevi usiamo using namespace std; per scrivere cout, string e vector senza ripetere std::. Non sostituisce gli include. Nei progetti più grandi e negli header è preferibile limitare questa direttiva, per evitare nomi ambigui.

ESEMPIO 1

Un personaggio, due dati

Prima tenevamo nome e vita in variabili separate. Una struct definisce un nuovo tipo che raggruppa quei dati. La definizione finisce con un punto e virgola; il punto seleziona un campo.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
};

int main() {
  Personaggio eroe;
  eroe.nome = "Brina";
  eroe.vita = 100;
  cout << eroe.nome << ": " << eroe.vita << '\n';
}

Risultato atteso

Brina: 100

Modifica tu. Aggiungi il campo livello e stampalo. Non aggiungere ancora metodi o altre struct.

ESEMPIO 2

Mago, Arciere e Goblin

Creiamo tre variabili dello stesso tipo. I valori iniziali tra graffe seguono l’ordine dei campi. Il ruolo è per ora soltanto un testo: non stiamo ancora creando classi diverse per ciascuna professione.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  string ruolo;
  int vita;
};

int main() {
  Personaggio mago{"Aria", "Mago", 80};
  Personaggio arciere{"Lio", "Arciere", 90};
  Personaggio nemico{"Gruk", "Goblin", 40};
  cout << mago.nome << " - " << mago.ruolo << ": " << mago.vita << '\n';
  cout << arciere.nome << " - " << arciere.ruolo << ": " << arciere.vita << '\n';
  cout << nemico.nome << " - " << nemico.ruolo << ": " << nemico.vita << '\n';
}

Risultato atteso

Aria - Mago: 80
Lio - Arciere: 90
Gruk - Goblin: 40

Modifica tu. Aggiungi una Guerriera e un Orco. Mantieni lo stesso tipo Personaggio e scegli valori diversi.

ESEMPIO 3

Creare un personaggio da tastiera

Ora i valori arrivano da input. getline legge anche un nome con spazi; cin legge il numero successivo. In questa prova assumiamo una vita intera non negativa.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
};

int main() {
  Personaggio eroe;
  getline(cin, eroe.nome);
  cin >> eroe.vita;
  cout << eroe.nome << ": " << eroe.vita << '\n';
}

Dati da inserire nel terminale

Nora la guaritrice
70

Risultato atteso

Nora la guaritrice: 70

Modifica tu. Inserisci un altro nome e un’altra vita. Poi aggiungi un controllo che rifiuti una vita negativa.

ESEMPIO 4

Passare una copia o l’originale

Una funzione con Personaggio p riceve una copia; con Personaggio& p modifica l’oggetto originale. Riprendiamo i riferimenti del capitolo 12. Non è necessario un puntatore per modificare la vita.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
  int attacco;
};

void dannoAllaCopia(Personaggio p) { p.vita -= 10; }
void dannoAllOriginale(Personaggio& p) { p.vita -= 10; }

int main() {
  Personaggio eroe{"Brina", 100, 12};
  dannoAllaCopia(eroe);
  cout << "Dopo la copia: " << eroe.vita << '\n';
  dannoAllOriginale(eroe);
  cout << "Dopo il riferimento: " << eroe.vita << '\n';
}

Risultato atteso

Dopo la copia: 100
Dopo il riferimento: 90

Modifica tu. Cambia entrambe le sottrazioni in 20. Prima di eseguire, prevedi i due risultati.

ESEMPIO 5

Una funzione applica le regole del danno

Aggiungiamo due regole: un danno negativo non cura e la vita non deve scendere sotto zero. Una struct con campi pubblici non impone da sola queste regole: dobbiamo rispettarle nel codice.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
  int attacco;
};

void subisciDanno(Personaggio& p, int danno) {
  if (danno <= 0) return;
  p.vita -= danno;
  if (p.vita < 0) p.vita = 0;
}

int main() {
  Personaggio goblin{"Gruk", 30, 6};
  subisciDanno(goblin, -10);
  cout << goblin.vita << '\n';
  subisciDanno(goblin, 12);
  cout << goblin.vita << '\n';
  subisciDanno(goblin, 50);
  cout << goblin.vita << '\n';
}

Risultato atteso

30
18
0

Modifica tu. Prova danno 0, un danno esattamente uguale alla vita e un danno maggiore della vita. Spiega perché il controllo serve.

ESEMPIO 6

Un gruppo di eroi in un vector

Ora raccogliamo più struct. const Personaggio& permette di leggere ogni elemento senza copiarlo o modificarlo. Il tipo dell’elemento resta lo stesso, anche se i personaggi hanno nomi e valori diversi.

main.cpp · programma completo

#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
  int attacco;
};

int main() {
  vector<Personaggio> squadra{
    {"Aria", 80, 10}, {"Lio", 90, 8}, {"Brina", 100, 12}
  };
  for (const Personaggio& eroe : squadra) {
    cout << eroe.nome << ": " << eroe.vita << " vita, " << eroe.attacco << " attacco" << '\n';
  }
}

Risultato atteso

Aria: 80 vita, 10 attacco
Lio: 90 vita, 8 attacco
Brina: 100 vita, 12 attacco

Modifica tu. Aggiungi Nora la Guaritrice al gruppo. Per ora anche lei ha soltanto dati: il comportamento di cura arriverà con i metodi.

ESEMPIO 7

Primo ciclo di gioco: squadra contro Orco

Riuniamo soltanto ciò che abbiamo già provato: struct, vector, funzioni, riferimenti, if e cicli. Ogni turno gli eroi vivi attaccano; se il nemico sopravvive, contrattacca un eroe vivo. I danni iniziali sono positivi, quindi lo scontro può concludersi. Non ci sono casualità: possiamo prevedere l’uscita.

main.cpp · programma completo

#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
  int attacco;
};

void subisciDanno(Personaggio& p, int danno) {
  if (danno <= 0) return;
  p.vita -= danno;
  if (p.vita < 0) p.vita = 0;
}

bool squadraViva(const vector<Personaggio>& squadra) {
  for (const Personaggio& eroe : squadra) {
    if (eroe.vita > 0) return true;
  }
  return false;
}

int main() {
  vector<Personaggio> squadra{
    {"Aria", 80, 10}, {"Lio", 90, 8}, {"Brina", 100, 12}
  };
  Personaggio nemico{"Orco", 60, 8};
  int turno = 1;

  while (nemico.vita > 0 && squadraViva(squadra)) {
    cout << "Turno " << turno << '\n';
    for (const Personaggio& eroe : squadra) {
      if (eroe.vita > 0 && nemico.vita > 0) {
        subisciDanno(nemico, eroe.attacco);
        cout << eroe.nome << " colpisce " << nemico.nome
             << ": " << nemico.vita << " vita" << '\n';
      }
    }
    // Il nemico contrattacca il primo eroe ancora vivo.
    if (nemico.vita > 0) {
      for (Personaggio& eroe : squadra) {
        if (eroe.vita > 0) {
          subisciDanno(eroe, nemico.attacco);
          cout << nemico.nome << " colpisce " << eroe.nome
               << ": " << eroe.vita << " vita" << '\n';
          break;
        }
      }
    }
    turno++;
  }
  if (nemico.vita == 0) cout << "Vittoria!" << '\n';
  else cout << "Sconfitta!" << '\n';
}

Risultato atteso

Turno 1
Aria colpisce Orco: 50 vita
Lio colpisce Orco: 42 vita
Brina colpisce Orco: 30 vita
Orco colpisce Aria: 72 vita
Turno 2
Aria colpisce Orco: 20 vita
Lio colpisce Orco: 12 vita
Brina colpisce Orco: 0 vita
Vittoria!

Modifica tu. Sostituisci l’Orco con un Goblin più debole, poi con un Drago con 300 vita e 100 attacco. Verifica anche la sconfitta. Imposta un eroe a vita 0: non deve attaccare. Se aggiungi la possibilità di attacco 0 per tutti, introduci anche un limite di turni e un esito di pareggio.

Spiega quali parti sono dati, quali operazioni e quali regole del gioco. Non basta ottenere l’uscita: cambia un valore iniziale, prevedi cosa succede e controlla anche un caso limite.
