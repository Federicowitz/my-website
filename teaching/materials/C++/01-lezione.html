01 | Il primo programma

Capitolo 01 · Teoria, esempio ragionato e verifica.

Prima di iniziare: nessuna conoscenza di C++ richiesta; serve un compilatore C++17.

Concetti e definizioni

Un programma è una sequenza di istruzioni. Il compilatore controlla il sorgente e produce un eseguibile; main è il punto di ingresso. Una variabile ha un tipo, un nome e un valore. Inizializzala prima di leggerla. cin legge dall’input standard e cout scrive sull’output standard.

Esempio completo

Salva come esempio.cpp. Compila con g++ -std=c++17 -Wall -Wextra esempio.cpp -o esempio; esegui ./esempio (PowerShell: .\esempio.exe).

#include <iostream>

int main() {
  int a{}, b{};
  if (!(std::cin >> a >> b)) return 1;
  std::cout << a + b << "\n";
}

Segui l’esecuzione

Con input 4 7 ottieni 11. L’operatore >> tenta una conversione: se scrivi una parola al posto di un numero, il controllo termina il programma.

Prova tu

Leggi base e altezza di un rettangolo e stampa area e perimetro.

Casi di prova e criteri di riuscita

3 5 → area 15, perimetro 16; 0 5 → area 0. Rifiuta dimensioni negative.

Prima di proseguire

Descrivi a parole l’algoritmo, esegui i casi di prova e spiega almeno un possibile errore. Poi passa agli esercizi del capitolo 01.
