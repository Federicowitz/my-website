13 | Struct e dati dei personaggi

Dalle variabili separate a un tipo che raggruppa i dati. Prima i dati, poi le operazioni: è il ponte verso classi e oggetti.

Prerequisito: capitolo 12. Nel laboratorio trovi esempi più piccoli prima del gioco completo.

Perché introdurre struct?

Nome, vita e attacco descrivono la stessa entità. Se li teniamo in variabili o array separati, dobbiamo ricordare quali valori appartengono allo stesso personaggio. Una struct li raccoglie in un unico tipo definito da noi. Il tipo descrive i campi; una sua variabile è un oggetto con valori propri.

Da C a C++

struct viene dal C, dove serve a raggruppare dati. In C++ rimane uno strumento attuale: può avere anche funzioni membro, costruttori ed ereditarietà. Qui iniziamo volontariamente con soli dati. Nella prossima lezione useremo class per introdurre regole e accesso controllato.

Tipo
La definizione Personaggio.
Oggetto
Una variabile concreta, come eroe o nemico.
Campo
Un dato membro, come vita.
Operatore punto
Con eroe.vita accedi alla vita di quell’oggetto.

Inizializza i dati prima di leggerli. Nella forma tra graffe l’ordine segue quello dei campi; una stringa richiede l’header string. Per leggere senza copiare usa un riferimento const; per modificare l’originale usa un riferimento non const.

Ogni esempio è indipendente. Crea un file main.cpp e copia un programma completo alla volta: non incollare più main nello stesso file. Compila con g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o gioco. Avvia .\gioco.exe in PowerShell oppure ./gioco su macOS/Linux. Salva e ricompila dopo ogni modifica.

Negli esempi brevi usiamo using namespace std; per scrivere cout, string e vector senza ripetere std::. Non sostituisce gli include. Nei progetti più grandi e negli header è preferibile limitare questa direttiva, per evitare nomi ambigui.

ESEMPIO 13

Esempio completo

Leggi il programma, prevedi il risultato e soltanto dopo eseguilo.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

struct Personaggio {
  string nome;
  int vita;
  int attacco;
};

void subisciDanno(Personaggio& p, int danno) {
  if (danno <= 0) return;
  p.vita -= danno;
  if (p.vita < 0) p.vita = 0;
}

int main() {
  Personaggio eroe{"Brina", 100, 12};
  subisciDanno(eroe, 25);
  cout << eroe.nome << ": " << eroe.vita << '\n';
}

Risultato atteso

Brina: 75

Modifica tu. Crea un Goblin e danneggialo separatamente. Poi spiega perché due oggetti dello stesso tipo possono avere valori diversi.

Segui l’esecuzione

subisciDanno riceve un riferimento allo stesso eroe del main. Riduce la vita da 100 a 75; nome e attacco non cambiano.
