05 | Menu con do while

Capitolo 05 · Teoria, esempio ragionato e verifica.

Prima di iniziare: completa il capitolo 04.

Concetti e definizioni

do while controlla la condizione dopo il corpo: almeno un’esecuzione è garantita. È utile quando devi mostrare un menu prima di conoscere la scelta. Il punto e virgola finale fa parte della sintassi. Una scelta invalida e un errore di lettura sono casi diversi: il secondo lascia lo stream in stato di errore.

Esempio completo

Salva come esempio.cpp. Compila con g++ -std=c++17 -Wall -Wextra esempio.cpp -o esempio; esegui ./esempio (PowerShell: .\esempio.exe).

#include <iostream>

int main() {
  int scelta{};
  do {
    std::cout << "1: saluta, 0: esci\n";
    if (!(std::cin >> scelta)) return 1;
    if (scelta == 1) std::cout << "Ciao!\n";
  } while (scelta != 0);
}

Segui l’esecuzione

1 1 0 mostra due saluti e termina. Un input testuale termina con codice 1 invece di creare un ciclo infinito.

Prova tu

Aggiungi al menu la scelta 2 per visualizzare un contatore dei saluti.

Casi di prova e criteri di riuscita

1 1 2 0 → il contatore mostra 2; 2 0 → mostra 0.

Prima di proseguire

Descrivi a parole l’algoritmo, esegui i casi di prova e spiega almeno un possibile errore. Poi passa agli esercizi del capitolo 05.
