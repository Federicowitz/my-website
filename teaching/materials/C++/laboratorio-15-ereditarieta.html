C++ · LABORATORIO 15 · 6 PASSI GUIDATI

Ereditarietà: eroi e nemici

Quando più tipi condividono una parte del comportamento, una classe base può raccogliere ciò che hanno in comune. Le derivate aggiungono le proprie caratteristiche.

Parti dalla spiegazione del capitolo 15. Ogni esempio qui aggiunge un concetto: puoi distribuire il laboratorio su più incontri. Gli ultimi passi riprendono il ciclo di gioco, con regole visibili e risultati riproducibili.

Ogni esempio è indipendente. Crea un file main.cpp e copia un programma completo alla volta: non incollare più main nello stesso file. Compila con g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o gioco. Avvia .\gioco.exe in PowerShell oppure ./gioco su macOS/Linux. Salva e ricompila dopo ogni modifica.

Negli esempi brevi usiamo using namespace std; per scrivere cout, string e vector senza ripetere std::. Non sostituisce gli include. Nei progetti più grandi e negli header è preferibile limitare questa direttiva, per evitare nomi ambigui.

Il percorso di lavoro

ESEMPIO 1

Una base comune e una specializzazione

Mago è un Personaggio. La scrittura : public Personaggio dichiara l’ereditarietà pubblica. In questo primo esempio la base espone un nome; il Mago usa il metodo ereditato e ne aggiunge uno proprio.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  string nome;
  void presentati() const { cout << "Sono " << nome << '\n'; }
};

class Mago : public Personaggio {
public:
  void saluta() const { cout << "Studio la magia." << '\n'; }
};

int main() {
  Mago mago;
  mago.nome = "Aria";
  mago.presentati();
  mago.saluta();
}

Risultato atteso

Sono Aria
Studio la magia.

Modifica tu. Aggiungi una classe Guerriero con un metodo proprio. Non copiare nome e presentati nella derivata.

ESEMPIO 2

Costruire prima la base, poi il Mago

Ripristiniamo i campi privati. La derivata inizializza la parte Personaggio con Personaggio(n). Il suo mana è un dato aggiuntivo. Un membro privato della base non diventa direttamente accessibile nella derivata.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string n) : nome(n) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
};

class Mago : public Personaggio {
private:
  int mana = 30;
public:
  Mago(string n) : Personaggio(n) {}
  int getMana() const { return mana; }
};

int main() {
  Mago mago("Aria");
  cout << mago.getNome() << ": " << mago.getVita() << " vita, "
       << mago.getMana() << " mana" << '\n';
}

Risultato atteso

Aria: 100 vita, 30 mana

Modifica tu. Aggiungi alla base un livello letto tramite un metodo. Osserva quali dati appartengono a tutti i personaggi e quali solo al Mago.

ESEMPIO 3

Due derivate: risorse diverse

Mago e Arciere condividono la base, ma mana e frecce appartengono alle rispettive classi. Per ora chiamiamo esplicitamente lancia e tira: non stiamo ancora scegliendo un comportamento tramite una funzione virtuale.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string n) : nome(n) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
};

class Mago : public Personaggio {
private:
  int mana = 30;
public:
  Mago(string n) : Personaggio(n) {}
  void lancia() {
    if (mana < 10) return;
    mana -= 10;
    cout << getNome() << " lancia. Mana: " << mana << '\n';
  }
};

class Arciere : public Personaggio {
private:
  int frecce = 3;
public:
  Arciere(string n) : Personaggio(n) {}
  void tira() {
    if (frecce == 0) return;
    frecce--;
    cout << getNome() << " tira. Frecce: " << frecce << '\n';
  }
};

int main() {
  Mago mago("Aria");
  Arciere arciere("Lio");
  mago.lancia();
  arciere.tira();
}

Risultato atteso

Aria lancia. Mana: 20
Lio tira. Frecce: 2

Modifica tu. Aggiungi un Guerriero con stamina e un metodo colpisci. Prova a esaurire ogni risorsa.

ESEMPIO 4

Eroi e nemici condividono la vita

Anche Goblin e Orco sono personaggi del gioco. Ereditano le stesse regole della vita. Il fatto di essere un nemico è una scelta del gioco, non una regola speciale del linguaggio.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string n) : nome(n) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
};

class Guerriero : public Personaggio {
public:
  Guerriero(string n) : Personaggio(n) {}
  void colpisci(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(20);
  }
};

class Goblin : public Personaggio {
public:
  Goblin(string n) : Personaggio(n) {}
};

int main() {
  Guerriero guerriero("Brina");
  Goblin goblin("Gruk");
  guerriero.colpisci(goblin);
  cout << goblin.getNome() << ": " << goblin.getVita() << '\n';
  goblin.subisciDanno(500);
  cout << goblin.getVita() << '\n';
}

Risultato atteso

Gruk: 80
0

Modifica tu. Aggiungi un metodo mordi al Goblin e fai danneggiare Brina. Nessuna derivata deve scrivere direttamente la vita della base.

ESEMPIO 5

È un personaggio, ma ha un equipaggiamento

Non tutto richiede ereditarietà. Un Arciere è un Personaggio e ha un Equipaggiamento: quest’ultimo è un membro, cioè composizione. L’arco non è un tipo di personaggio.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string n) : nome(n) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
};

struct Equipaggiamento { string arma; int bonus; };

class Arciere : public Personaggio {
private:
  Equipaggiamento equip;
public:
  Arciere(string n) : Personaggio(n), equip{"Arco", 3} {}
  void mostraArma() const {
    cout << getNome() << " usa " << equip.arma << ", bonus " << equip.bonus << '\n';
  }
};

int main() {
  Arciere arciere("Lio");
  arciere.mostraArma();
}

Risultato atteso

Lio usa Arco, bonus 3

Modifica tu. Dai un equipaggiamento anche al Guerriero. Spiega perché non scriveresti class Arco : public Personaggio.

ESEMPIO 6

Il duello tra tipi diversi

Le regole comuni rimangono nella base, i due attacchi sono nelle derivate. Il main conosce i tipi concreti e chiama metodi diversi: nel prossimo laboratorio vedremo come un ciclo possa chiamare la stessa operazione su personaggi diversi.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string n) : nome(n) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
};

class Guerriero : public Personaggio {
public:
  Guerriero(string n) : Personaggio(n) {}
  void colpisci(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(20);
  }
};

class Orco : public Personaggio {
public:
  Orco(string n) : Personaggio(n) {}
  void contrattacca(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(15);
  }
};

int main() {
  Guerriero eroe("Brina");
  Orco nemico("Borg");
  int turno = 1;
  while (eroe.vivo() && nemico.vivo()) {
    eroe.colpisci(nemico);
    if (nemico.vivo()) nemico.contrattacca(eroe);
    cout << "Turno " << turno << ": Brina " << eroe.getVita()
         << ", Borg " << nemico.getVita() << '\n';
    turno++;
  }
  if (eroe.vivo()) cout << "Vittoria!" << '\n';
  else cout << "Sconfitta!" << '\n';
}

Risultato atteso

Turno 1: Brina 85, Borg 80
Turno 2: Brina 70, Borg 60
Turno 3: Brina 55, Borg 40
Turno 4: Brina 40, Borg 20
Turno 5: Brina 40, Borg 0
Vittoria!

Modifica tu. Aggiungi un Mago alleato con lancia e un Goblin come secondo nemico. Prima usa chiamate esplicite; annota le ripetizioni che vorresti eliminare con un’unica interfaccia.
