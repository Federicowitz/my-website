06 | Contare con for

Capitolo 06 · Teoria, esempio ragionato e verifica.

Prima di iniziare: completa il capitolo 05.

Concetti e definizioni

for riunisce inizializzazione, condizione e aggiornamento. L’inizializzazione avviene una volta, la condizione prima del corpo, l’aggiornamento dopo ogni iterazione. Una variabile dichiarata nell’intestazione esiste nel ciclo. Usa intervalli chiari: i < n visita n indici da 0 a n-1.

Esempio completo

Salva come esempio.cpp. Compila con g++ -std=c++17 -Wall -Wextra esempio.cpp -o esempio; esegui ./esempio (PowerShell: .\esempio.exe).

#include <iostream>

int main() {
  int somma = 0;
  for (int i = 1; i <= 5; ++i) {
    somma += i;
  }
  std::cout << somma;
}

Segui l’esecuzione

Ottieni 15. Cambiare <= in < esclude 5 e produce 10: è un tipico errore di confine.

Prova tu

Leggi n tra 0 e 100 e stampa i primi n numeri pari, partendo da 0.

Casi di prova e criteri di riuscita

n=4 → 0 2 4 6; n=0 → nessun numero; n=1 → 0.

Prima di proseguire

Descrivi a parole l’algoritmo, esegui i casi di prova e spiega almeno un possibile errore. Poi passa agli esercizi del capitolo 06.
