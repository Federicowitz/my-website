Polimorfismo: un gruppo di personaggi

Un unico punto di chiamata può produrre comportamenti diversi, scelti in base al tipo effettivo dell’oggetto: un Mago lancia un incantesimo, un Arciere scocca una freccia.

Parti dalla spiegazione del capitolo 16. Ogni esempio qui aggiunge un concetto: puoi distribuire il laboratorio su più incontri. Gli ultimi passi riprendono il ciclo di gioco, con regole visibili e risultati riproducibili.

Ogni esempio è indipendente. Crea un file main.cpp e copia un programma completo alla volta: non incollare più main nello stesso file. Compila con g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o gioco. Avvia .\gioco.exe in PowerShell oppure ./gioco su macOS/Linux. Salva e ricompila dopo ogni modifica.

Negli esempi brevi usiamo using namespace std; per scrivere cout, string e vector senza ripetere std::. Non sostituisce gli include. Nei progetti più grandi e negli header è preferibile limitare questa direttiva, per evitare nomi ambigui.

Il percorso di lavoro

  1. Prima di virtual: conta il tipo del riferimento
  2. Virtual e override: cambia una regola

ESEMPIO 1

Prima di virtual: conta il tipo del riferimento

Partiamo da un controesempio compilabile. Il metodo non è virtuale: attraverso un riferimento Personaggio la chiamata usa il metodo di Personaggio, anche quando l’oggetto originale è un Mago.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  string azione() const { return "Colpo normale"; }
};
class Mago : public Personaggio {
public:
  string azione() const { return "Incantesimo"; }
};

int main() {
  Mago mago;
  const Personaggio& riferimento = mago;
  cout << mago.azione() << '\n';
  cout << riferimento.azione() << '\n';
}

Risultato atteso

Incantesimo
Colpo normale

Modifica tu. Prevedi l’uscita prima di eseguire. Non dire ancora che avere due metodi con lo stesso nome produce automaticamente polimorfismo dinamico.

ESEMPIO 2

Virtual e override: cambia una regola

virtual nella base permette di scegliere il metodo in base al tipo effettivo dell’oggetto. override nella derivata chiede al compilatore di verificare la corrispondenza. Il const deve corrispondere. Il distruttore virtuale rende corretta anche un’eventuale distruzione attraverso un puntatore alla base; qui non usiamo new o delete.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  virtual string azione() const { return "Colpo normale"; }
  virtual ~Personaggio() = default;
};
class Mago : public Personaggio {
public:
  string azione() const override { return "Incantesimo"; }
};
class Arciere : public Personaggio {
public:
  string azione() const override { return "Freccia"; }
};

int main() {
  Mago mago;
  const Personaggio& riferimento = mago;
  cout << mago.azione() << '\n';
  cout << riferimento.azione() << '\n';
}

Risultato atteso

Incantesimo
Incantesimo

Modifica tu. Togli const soltanto dal metodo della derivata mantenendo override: il compilatore deve segnalare l’errore. Poi ripristinalo.

ESEMPIO 3

Una funzione, due comportamenti

La funzione turno conosce l’interfaccia Personaggio e riceve un riferimento. Non deve chiedere se l’oggetto è un Mago o un Arciere: la chiamata virtuale seleziona il comportamento.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  virtual string azione() const { return "Colpo normale"; }
  virtual ~Personaggio() = default;
};
class Mago : public Personaggio {
public:
  string azione() const override { return "Incantesimo"; }
};
class Arciere : public Personaggio {
public:
  string azione() const override { return "Freccia"; }
};

void turno(const Personaggio& p) { cout << p.azione() << '\n'; }

int main() {
  Mago mago;
  Arciere arciere;
  turno(mago);
  turno(arciere);
}

Risultato atteso

Incantesimo
Freccia

Modifica tu. Aggiungi Guerriero con azione Scudo e Goblin con azione Morso. La funzione turno deve rimanere identica.

ESEMPIO 4

La trappola della copia: object slicing

Se copiamo il Mago in un parametro Personaggio passato per valore, creiamo un nuovo oggetto che contiene soltanto la parte base. È object slicing: virtual non può recuperare una parte derivata che nella copia non esiste.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  virtual string azione() const { return "Colpo normale"; }
  virtual ~Personaggio() = default;
};
class Mago : public Personaggio {
public:
  string azione() const override { return "Incantesimo"; }
};
class Arciere : public Personaggio {
public:
  string azione() const override { return "Freccia"; }
};

void perValore(Personaggio p) { cout << p.azione() << '\n'; }
void perRiferimento(const Personaggio& p) { cout << p.azione() << '\n'; }

int main() {
  Mago mago;
  perValore(mago);
  perRiferimento(mago);
}

Risultato atteso

Colpo normale
Incantesimo

Modifica tu. Spiega perché un vector contenente copie di Mago e Arciere perderebbe le loro specializzazioni. Non sostituire i riferimenti con copie nel prossimo esempio.

ESEMPIO 5

Un gruppo con riferimenti tramite puntatori

Il vector contiene indirizzi di oggetti locali già esistenti. Il puntatore non possiede né crea l’oggetto. Con p->azione() chiamiamo il metodo dell’oggetto puntato; tutti gli oggetti restano vivi durante il ciclo.

main.cpp · programma completo

#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Personaggio {
public:
  virtual string azione() const { return "Colpo normale"; }
  virtual ~Personaggio() = default;
};
class Mago : public Personaggio {
public:
  string azione() const override { return "Incantesimo"; }
};
class Arciere : public Personaggio {
public:
  string azione() const override { return "Freccia"; }
};

int main() {
  Mago mago;
  Arciere arciere;
  vector<Personaggio*> gruppo{&mago, &arciere};
  for (const Personaggio* p : gruppo) {
    cout << p->azione() << '\n';
  }
}

Risultato atteso

Incantesimo
Freccia

Modifica tu. Aggiungi Guerriero, Guaritrice e Goblin con comportamenti diversi. Non cambiare il ciclo. Non restituire gli indirizzi di questi oggetti da una funzione che li distrugge.

ESEMPIO 6

Una classe astratta e un attacco comune

= 0 dichiara un metodo virtuale puro. Non possiamo creare un Personaggio generico: ogni tipo concreto deve fornire il danno. attacca è una regola comune, ma dentro chiama danno e ottiene il valore della derivata.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita;
public:
  Personaggio(string n, int v) : nome(n), vita(v) {}
  virtual ~Personaggio() = default;
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
  virtual int danno() const = 0;
  void attacca(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(danno());
  }
};
class Mago : public Personaggio {
public:
  Mago(string n) : Personaggio(n, 80) {}
  int danno() const override { return 20; }
};
class Arciere : public Personaggio {
public:
  Arciere(string n) : Personaggio(n, 90) {}
  int danno() const override { return 12; }
};

int main() {
  Mago mago("Aria");
  Arciere arciere("Lio");
  mago.attacca(arciere);
  arciere.attacca(mago);
  cout << mago.getNome() << ": " << mago.getVita() << '\n';
  cout << arciere.getNome() << ": " << arciere.getVita() << '\n';
}

Risultato atteso

Aria: 68
Lio: 70

Modifica tu. Aggiungi un Guerriero con 120 vita e danno 15. Prova a creare direttamente Personaggio: il compilatore deve rifiutarlo perché è astratta.

ESEMPIO 7

Gioco finale: squadra contro il boss Drago

Ora il ciclo usa sempre attacca, anche per classi diverse. Il controllo di vittoria arriva dopo gli attacchi degli eroi: un boss sconfitto non contrattacca. Il boss colpisce il primo eroe vivo. Nessun puntatore possiede gli oggetti: sono tutti locali al main.

main.cpp · programma completo

#include <iostream>
#include <string>
#include <vector>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita;
public:
  Personaggio(string n, int v) : nome(n), vita(v) {}
  virtual ~Personaggio() = default;
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int n) {
    if (n <= 0) return;
    vita -= n;
    if (vita < 0) vita = 0;
  }
  virtual int danno() const = 0;
  void attacca(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(danno());
  }
};
class Mago : public Personaggio {
public:
  Mago(string n) : Personaggio(n, 80) {}
  int danno() const override { return 20; }
};
class Arciere : public Personaggio {
public:
  Arciere(string n) : Personaggio(n, 90) {}
  int danno() const override { return 12; }
};
class Guerriero : public Personaggio {
public:
  Guerriero(string n) : Personaggio(n, 120) {}
  int danno() const override { return 15; }
};
class Drago : public Personaggio {
public:
  Drago(string n) : Personaggio(n, 110) {}
  int danno() const override { return 25; }
};

bool squadraViva(const vector<Personaggio*>& squadra) {
  for (const Personaggio* p : squadra) if (p->vivo()) return true;
  return false;
}

int main() {
  Mago mago("Aria");
  Arciere arciere("Lio");
  Guerriero guerriero("Brina");
  Drago boss("Fiamma");
  vector<Personaggio*> squadra{&mago, &arciere, &guerriero};
  int turno = 1;

  while (boss.vivo() && squadraViva(squadra)) {
    cout << "Turno " << turno << '\n';
    for (const Personaggio* p : squadra) {
      if (p->vivo() && boss.vivo()) {
        p->attacca(boss);
        cout << p->getNome() << " attacca: boss " << boss.getVita() << '\n';
      }
    }
    if (boss.vivo()) {
      for (Personaggio* p : squadra) {
        if (p->vivo()) {
          boss.attacca(*p);
          cout << "Boss attacca " << p->getNome() << ": " << p->getVita() << '\n';
          break;
        }
      }
    }
    turno++;
  }
  if (!boss.vivo()) cout << "Vittoria!" << '\n';
  else cout << "Sconfitta!" << '\n';
}

Risultato atteso

Turno 1
Aria attacca: boss 90
Lio attacca: boss 78
Brina attacca: boss 63
Boss attacca Aria: 55
Turno 2
Aria attacca: boss 43
Lio attacca: boss 31
Brina attacca: boss 16
Boss attacca Aria: 30
Turno 3
Aria attacca: boss 0
Vittoria!

Modifica tu. Aggiungi Goblin e Orco come altri tipi concreti e scegli un avversario diverso mantenendo il ciclo. Poi aumenta la vita del Drago a 500 e il danno a 100: deve comparire Sconfitta. Solo dopo aggiungi una Guaritrice e un metodo virtuale eseguiTurno(Personaggio& nemico, Personaggio& alleato): i combattenti attaccano, lei cura l’alleato vivo senza superare la sua vita massima. Questa estensione richiede di progettare un’interfaccia adatta anche alla cura.
