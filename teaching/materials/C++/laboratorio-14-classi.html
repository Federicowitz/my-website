C++ · LABORATORIO 14 · 7 PASSI GUIDATI

Classi, oggetti e incapsulamento

Raggruppare i dati non basta quando vogliamo imporre regole. Una classe può esporre operazioni e controllare come cambia il proprio stato.

Parti dalla spiegazione del capitolo 14. Ogni esempio qui aggiunge un concetto: puoi distribuire il laboratorio su più incontri. Gli ultimi passi riprendono il ciclo di gioco, con regole visibili e risultati riproducibili.

Ogni esempio è indipendente. Crea un file main.cpp e copia un programma completo alla volta: non incollare più main nello stesso file. Compila con g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o gioco. Avvia .\gioco.exe in PowerShell oppure ./gioco su macOS/Linux. Salva e ricompila dopo ogni modifica.

Negli esempi brevi usiamo using namespace std; per scrivere cout, string e vector senza ripetere std::. Non sostituisce gli include. Nei progetti più grandi e negli header è preferibile limitare questa direttiva, per evitare nomi ambigui.

ESEMPIO 1

Dalla struct a una classe con dati pubblici

Facciamo il cambio più piccolo: usiamo class, ma scriviamo public per mantenere l’accesso ai campi. In C++ struct e class possono entrambe avere dati e metodi; cambia l’accesso predefinito, non il fatto di poter creare oggetti.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
public:
  string nome;
  int vita;
};

int main() {
  Personaggio eroe;
  eroe.nome = "Brina";
  eroe.vita = 100;
  cout << eroe.nome << ": " << eroe.vita << '\n';
}

Risultato atteso

Brina: 100

Modifica tu. Togli public e prova a compilare: l’accesso ai campi dal main deve essere rifiutato. Poi ripristinalo.

ESEMPIO 2

Vita privata e metodi pubblici

Ora la vita è privata e il metodo subisciDanno protegge le regole. getVita legge lo stato; const dopo le parentesi indica che quel metodo non modifica i normali dati dell’oggetto.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  int vita = 100;
public:
  int getVita() const { return vita; }
  void subisciDanno(int danno) {
    if (danno <= 0) return;
    vita -= danno;
    if (vita < 0) vita = 0;
  }
};

int main() {
  Personaggio eroe;
  eroe.subisciDanno(-5);
  cout << eroe.getVita() << '\n';
  eroe.subisciDanno(20);
  cout << eroe.getVita() << '\n';
  eroe.subisciDanno(500);
  cout << eroe.getVita() << '\n';
}

Risultato atteso

100
80
0

Modifica tu. Prova eroe.vita = -10: il compilatore deve impedirlo. Rimuovi quella riga e ripeti i casi limite del danno.

ESEMPIO 3

Il costruttore e due oggetti indipendenti

Il costruttore ha lo stesso nome della classe e non ha un tipo di ritorno. Viene eseguito durante la creazione dell’oggetto. In questa prima versione assegniamo il nome nel suo corpo; la vita parte da 100 grazie al valore iniziale del campo.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita = 100;
public:
  Personaggio(string nuovoNome) { nome = nuovoNome; }
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int danno) {
    if (danno <= 0) return;
    vita -= danno;
    if (vita < 0) vita = 0;
  }
};

int main() {
  Personaggio prima("Aria");
  Personaggio seconda("Brina");
  prima.subisciDanno(20);
  cout << prima.getNome() << ": " << prima.getVita() << '\n';
  cout << seconda.getNome() << ": " << seconda.getVita() << '\n';
}

Risultato atteso

Aria: 80
Brina: 100

Modifica tu. Danneggia anche il secondo oggetto. Spiega perché chiamare un metodo su prima non modifica seconda.

ESEMPIO 4

Scegliere la vita iniziale

Aggiungiamo un parametro al costruttore. La lista dopo i due punti inizializza i membri prima del corpo: non è ereditarietà. Nel corpo correggiamo un valore negativo.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita;
public:
  Personaggio(string n, int v) : nome(n), vita(v) {
    if (vita < 0) vita = 0;
  }
  string getNome() const { return nome; }
  int getVita() const { return vita; }
};

int main() {
  Personaggio goblin("Gruk", 40);
  Personaggio errato("Ombra", -10);
  cout << goblin.getNome() << ": " << goblin.getVita() << '\n';
  cout << errato.getNome() << ": " << errato.getVita() << '\n';
}

Risultato atteso

Gruk: 40
Ombra: 0

Modifica tu. Crea un Orco con vita 150 e un Drago con vita 300. Aggiungi un livello iniziale e un metodo per leggerlo.

ESEMPIO 5

Un Mago con una risorsa: il mana

La classe Mago qui è autonoma: non eredita ancora da Personaggio. Un metodo riesce soltanto se il mana basta e restituisce bool. Stampiamo l’esito per vedere sia il successo sia il fallimento.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Mago {
private:
  int mana = 30;
public:
  int getMana() const { return mana; }
  bool lanciaIncantesimo() {
    if (mana < 20) return false;
    mana -= 20;
    return true;
  }
};

int main() {
  Mago mago;
  cout << boolalpha;
  cout << mago.lanciaIncantesimo() << ": " << mago.getMana() << '\n';
  cout << mago.lanciaIncantesimo() << ": " << mago.getMana() << '\n';
}

Risultato atteso

true: 10
false: 10

Modifica tu. Cambia costo e mana iniziale. Se il mana è esattamente uguale al costo, il lancio deve riuscire e lasciare 0.

ESEMPIO 6

Due oggetti collaborano: la Guaritrice

Una classe può ricevere un riferimento a un oggetto di un’altra classe. La Guaritrice non tocca direttamente la vita privata: chiama riceviCura, che impedisce di superare il massimo di 100.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  int vita = 100;
public:
  int getVita() const { return vita; }
  void subisciDanno(int n) {
    if (n > 0) vita -= n;
    if (vita < 0) vita = 0;
  }
  void riceviCura(int n) {
    if (n > 0) vita += n;
    if (vita > 100) vita = 100;
  }
};

class Guaritrice {
private:
  int energia = 2;
public:
  void cura(Personaggio& alleato) {
    if (energia == 0) return;
    alleato.riceviCura(30);
    energia--;
  }
};

int main() {
  Personaggio guerriero;
  Guaritrice nora;
  guerriero.subisciDanno(50);
  cout << guerriero.getVita() << '\n';
  nora.cura(guerriero);
  cout << guerriero.getVita() << '\n';
  nora.cura(guerriero);
  cout << guerriero.getVita() << '\n';
  nora.cura(guerriero);
  cout << guerriero.getVita() << '\n';
}

Risultato atteso

50
80
100
100

Modifica tu. Aggiungi getEnergia e stampalo dopo ogni cura. Qui la cura può riportare in vita anche un oggetto con vita 0: scegli se mantenere questa regola o rifiutare la cura a un personaggio sconfitto.

ESEMPIO 7

Il ciclo di gioco con gli oggetti

Riprendiamo il duello, spostando l’attacco e le regole della vita nei metodi. Usiamo solo valori iniziali positivi, scelti nel programma. Gli oggetti sono ancora dello stesso tipo: i ruoli dipendono dai loro dati.

main.cpp · programma completo

#include <iostream>
#include <string>
using namespace std;

class Personaggio {
private:
  string nome;
  int vita;
  int attacco;
public:
  Personaggio(string n, int v, int a) : nome(n), vita(v), attacco(a) {}
  string getNome() const { return nome; }
  int getVita() const { return vita; }
  bool vivo() const { return vita > 0; }
  void subisciDanno(int danno) {
    if (danno <= 0) return;
    vita -= danno;
    if (vita < 0) vita = 0;
  }
  void attacca(Personaggio& bersaglio) const {
    if (vivo() && bersaglio.vivo()) bersaglio.subisciDanno(attacco);
  }
};

int main() {
  Personaggio eroe("Brina", 60, 15);
  Personaggio nemico("Goblin", 40, 8);
  int turno = 1;
  while (eroe.vivo() && nemico.vivo()) {
    eroe.attacca(nemico);
    if (nemico.vivo()) nemico.attacca(eroe);
    cout << "Turno " << turno << ": " << eroe.getNome() << " " << eroe.getVita()
         << ", " << nemico.getNome() << " " << nemico.getVita() << '\n';
    turno++;
  }
  if (eroe.vivo()) cout << "Vittoria!" << '\n';
  else cout << "Sconfitta!" << '\n';
}

Risultato atteso

Turno 1: Brina 52, Goblin 25
Turno 2: Brina 44, Goblin 10
Turno 3: Brina 44, Goblin 0
Vittoria!

Modifica tu. Sostituisci il Goblin con un Orco più resistente. Verifica che un nemico appena sconfitto non contrattacchi. Poi aggiungi una cura ogni due turni usando le regole dell’esempio precedente.
