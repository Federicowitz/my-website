03 | Decisioni e condizioni

Capitolo 03 · Teoria, esempio ragionato e verifica.

Prima di iniziare: completa il capitolo 02.

Concetti e definizioni

if esegue un ramo quando una condizione è vera; else gestisce il caso alternativo. Una catena else if sceglie il primo ramo vero. && richiede entrambe le condizioni, || almeno una, ! inverte un valore logico. && e || valutano da sinistra e possono evitare il secondo operando.

Esempio completo

Salva come esempio.cpp. Compila con g++ -std=c++17 -Wall -Wextra esempio.cpp -o esempio; esegui ./esempio (PowerShell: .\esempio.exe).

#include <iostream>

int main() {
  int eta{};
  if (!(std::cin >> eta) || eta < 0) return 1;
  if (eta < 14) std::cout << "ridotto";
  else if (eta < 65) std::cout << "intero";
  else std::cout << "senior";
}

Segui l’esecuzione

13 → ridotto; 14 → intero; 65 → senior. L’ordine dei confronti stabilisce i confini dei rami.

Prova tu

Calcola una spedizione: gratuita da 50 euro, altrimenti 5 euro. Rifiuta importi negativi.

Casi di prova e criteri di riuscita

49.99 → 5; 50 → 0; -1 → errore. Prova sempre i valori di confine.

Prima di proseguire

Descrivi a parole l’algoritmo, esegui i casi di prova e spiega almeno un possibile errore. Poi passa agli esercizi del capitolo 03.
