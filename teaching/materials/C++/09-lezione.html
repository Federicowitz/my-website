09 | Funzioni e parametri

Capitolo 09 · Teoria, esempio ragionato e verifica.

Prima di iniziare: completa il capitolo 08.

Concetti e definizioni

Una funzione isola un compito con nome, parametri e tipo di ritorno. I parametri per valore sono copie; i riferimenti permettono di operare sull’oggetto del chiamante. Una funzione pura dipende dai parametri e non modifica stato esterno. Il contratto specifica input ammessi e risultato, rendendo possibili test indipendenti.

Esempio completo

Salva come esempio.cpp. Compila con g++ -std=c++17 -Wall -Wextra esempio.cpp -o esempio; esegui ./esempio (PowerShell: .\esempio.exe).

#include <iostream>

int quadrato(int n) { return n * n; }
int main() {
  std::cout << quadrato(4) << "\n";
}

Segui l’esecuzione

Ottieni 16. La funzione restituisce un valore, mentre main decide come mostrarlo. Usa valori piccoli per evitare overflow di int.

Prova tu

Scrivi bool pari(int n) e richiamala per ogni numero da -3 a 3.

Casi di prova e criteri di riuscita

-2, 0 e 2 → true; -3, -1, 1 e 3 → false.

Prima di proseguire

Descrivi a parole l’algoritmo, esegui i casi di prova e spiega almeno un possibile errore. Poi passa agli esercizi del capitolo 09.
