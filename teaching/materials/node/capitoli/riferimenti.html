Nel materialeCome leggerlo oggi
Node 14/16Usa una linea LTS ancora supportata; verifica lo stato nella tabella ufficiale.
require e module.exportsCommonJS è ancora supportato. ESM offre import/export standard; scegli il formato in modo esplicito.
NodemonResta valido; per il riavvio di base esiste anche il watch integrato in Node.
Callback di fsRestano valide; Promise e await semplificano molti flussi asincroni.
Vecchie route ExpressGli esempi nuovi si riferiscono a Express 5; controlla le differenze prima di copiare percorsi da Express 4.
Array importato = copiaL’importazione non copia automaticamente l’array e modificare l’oggetto non riscrive il file sorgente.
Statico = SSRServire HTML già scritto è statico; SSR genera la vista lato server usando dati.
Risposta 200 per ogni esitoUsa gli status secondo il risultato: creazione 201, assenza 404, input errato 400.
